Use this guide if you already have an overseas network and want to connect to a MiyaIP static residential **Native proxy** on iPhone.

## Prepare your device

1. Open **Settings → Privacy & Security → Location Services** and turn **Location Services** off.

<Frame>
  <img src="/images/tutorials/o_ios_sr_1.png" alt="Turn off Location Services in iPhone settings" style={{ width: "100%", maxWidth: "480px" }} />
</Frame>

2. Open **Settings → General**. Adjust the time zone under **Date & Time**, and the **Language & Region** settings, to match the proxy IP's target country or region. Choose the target country's language and avoid using Simplified Chinese.

<Frame>
  <img src="/images/tutorials/o_ios_sr_2.png" alt="Adjust the date, time, language, and region on iPhone" style={{ width: "100%", maxWidth: "480px" }} />
</Frame>

See [Device preparation](/device-preparation) for more details.

## Before you connect

- Install **Shadowrocket** on your iPhone and prepare a working overseas network node for your first network hop.
- Get the SOCKS5 node and QR code for your static residential **Native proxy** from the MiyaIP dashboard. Make sure you have the proxy host, port, username, and password.

<Frame>
  <img src="/images/tutorials/4.png" alt="View the static residential native proxy QR code and credentials in MiyaIP" />
</Frame>

## Configuration steps

<Steps>
  <Step title="Scan the native proxy QR code">
    Open Shadowrocket and tap the **scan button** in the upper-left corner. Scan the native proxy QR code in the MiyaIP dashboard to import your static IP node.

    <Frame>
      <img src="/images/tutorials/o_ios_sr_4.png" alt="Tap the scan button in the upper-left corner of Shadowrocket" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="Open the node settings">
    Tap the **exclamation mark button** beside the static IP node you just imported.

    <Frame>
      <img src="/images/tutorials/o_ios_sr_5.png" alt="Open the static IP node settings with the exclamation mark button" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="Open Proxy through">
    Tap **Proxy through** in the node settings.

    <Frame>
      <img src="/images/tutorials/o_ios_sr_6.png" alt="Open Proxy through in the Shadowrocket node settings" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="Select your overseas node">
    In **Proxy through**, select the overseas network node you prepared.

    <Frame>
      <img src="/images/tutorials/o_ios_sr_7.png" alt="Select your existing overseas network node for Proxy through" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="Check and save the configuration">
    Confirm that the protocol is **SOCKS5**. Check your MiyaIP native proxy **host, port, username, and password**. Confirm that **Proxy through** uses the correct overseas node, then tap **Save**.

    <Frame>
      <img src="/images/tutorials/o_ios_sr_8.png" alt="Check the SOCKS5 protocol and Proxy through setting before saving" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="Connect with the static IP node">
    Return to the Shadowrocket home screen and select your **MiyaIP static IP node**. Set **Global routing** to **Proxy**, then turn on the **connection switch** at the top.

    <Frame>
      <img src="/images/tutorials/o_ios_sr_9.png" alt="Select the static IP node and start the Shadowrocket proxy connection" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="Verify your exit IP">
    Open [whoer.net](https://whoer.net) in your browser. Confirm that the displayed **IP address** matches the MiyaIP static residential IP you purchased and that the **country or region** is correct.

  </Step>
</Steps>
