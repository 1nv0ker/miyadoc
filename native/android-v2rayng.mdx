Use this guide if you already have an overseas network node and want to connect to a MiyaIP static residential **Native proxy** on Android.

Download and install v2rayNG from the [official v2rayNG releases page](https://github.com/2dust/v2rayNG/releases). You need a network connection that can access GitHub.

## Prepare your device

1. Open **Settings** and set your **time zone**, **language**, and **region** to match the proxy IP's target country or region. Menu names vary by Android device. Choose the target country's language and avoid using Simplified Chinese.

<Frame>
  <img src="/images/tutorials/o_and_v2_1.png" alt="Adjust the date, time, language, and region on Android" style={{ width: "100%", maxWidth: "480px" }} />
</Frame>

2. Find **Location** in **Settings** and turn it off.

<Frame>
  <img src="/images/tutorials/o_and_v2_2.png" alt="Turn off Location in Android settings" style={{ width: "100%", maxWidth: "480px" }} />
</Frame>

See [Device preparation](/device-preparation) for more details.

## Before you connect

- Install **v2rayNG** on your Android phone and prepare a working overseas network node for your first network hop.
- Get the SOCKS5 credentials for your static residential **Native proxy** from the MiyaIP dashboard: **host, port, username, and password**.

## Configuration steps

<Steps>
  <Step title="Import and edit your overseas node">
    Import your existing overseas network nodes into v2rayNG. Select a working node and tap its **edit button**.

    <Frame>
      <img src="/images/tutorials/o_and_v2_3.png" alt="Select and edit your existing overseas network node in v2rayNG" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="Give the node a unique name">
    Change the overseas node's **name** so that no other node has the same name. Tap **✓** in the upper-right corner to save and remember the name.

    <Frame>
      <img src="/images/tutorials/o_and_v2_4.png" alt="Give the overseas network node a unique name and save" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="Open Subscription group settings">
    Tap the **three-line menu button** in the upper-left corner, then select **Subscription group settings**.

    <Frame>
      <img src="/images/tutorials/o_and_v2_5.png" alt="Open the side menu in the upper-left corner of v2rayNG" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>

    <Frame>
      <img src="/images/tutorials/o_and_v2_6.png" alt="Select Subscription group settings in the v2rayNG menu" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="Create a group with a Pre-proxy">
    Tap the **plus button** in the upper-right corner to add a group. Enter a **Remark** and fill **Pre-proxy** with the overseas node name you just set. Tap **✓** to save.

    <Frame>
      <img src="/images/tutorials/o_and_v2_7.png" alt="Tap the plus button on the Subscription group settings page" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>

    <Frame>
      <img src="/images/tutorials/o_and_v2_8.png" alt="Enter a group remark and the overseas Pre-proxy node name" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="Add a SOCKS5 static IP node">
    Return to the node list and select the group you just created. Tap the **plus button** in the upper-right corner, select **Manual input**, and choose **SOCKS5** to add the static IP node.

    <Frame>
      <img src="/images/tutorials/o_and_v2_9.png" alt="Tap the plus button in the v2rayNG node list" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>

    <Frame>
      <img src="/images/tutorials/o_and_v2_10.png" alt="Select Manual input for a SOCKS5 node" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="Enter your MiyaIP proxy credentials">
    Enter a **Remark** for the static IP node. Fill the **Server, Port, Username, and Password** fields with your MiyaIP native proxy **host, port, username, and password**, then tap **✓** in the upper-right corner to save.

    <Frame>
      <img src="/images/tutorials/o_and_v2_11.png" alt="Enter the MiyaIP static residential SOCKS5 credentials and save the node" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="Connect and test latency">
    Select the **MiyaIP static IP node** you configured and tap the **start button** at the bottom. Tap the **blank area** on the main screen to run a latency test.

    <Frame>
      <img src="/images/tutorials/o_and_v2_12.png" alt="Select the MiyaIP static IP node and start the connection and latency test" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="Verify your exit IP">
    After the latency test responds, open [whoer.net](https://whoer.net) in your browser. Confirm that the displayed **IP address** matches the MiyaIP static residential IP you purchased and that the **country or region** is correct.

  </Step>
</Steps>
