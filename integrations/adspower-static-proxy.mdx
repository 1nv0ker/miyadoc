This guide walks you through the complete workflow for using a MiyaIP static residential proxy inside an AdsPower browser profile — from locating your proxy credentials in the MiyaIP dashboard, to creating a fully configured browser environment in AdsPower, to verifying that the connection is live and working. By the end, your AdsPower profile will route all traffic through your chosen MiyaIP residential IP.

<Note>
  If you are using a **relay proxy** (中转代理) instead of the original proxy, make sure to close any other VPN or proxy software running on your computer before connecting. Running multiple proxy or VPN clients simultaneously can cause connection conflicts and prevent the relay proxy from working correctly.
</Note>

## Setup Steps

<Steps>
  <Step title="Extract Your Proxy Credentials from the MiyaIP Dashboard">
    Log in to your MiyaIP account at [miyaip.com](https://miyaip.com) and navigate to the **Static Residential** section in the left sidebar.

    In the **Purchased IPs** (已购IP) tab, locate the IP row you want to use. You have two ways to retrieve the credentials:

    - **Copy icon** — click the copy icon in the **Original Proxy** (原始代理) or **Relay Proxy** (中转代理) column to copy the full proxy string to your clipboard. The string includes the IP address, port, username, and password.
    - **QR code icon** — click the QR icon on the row to open a modal that displays the proxy details. The modal includes tabs for **Shadowrocket**, **Nekobox**, and **V2ray** — for this AdsPower integration, you only need the raw IP, port, username, and password values shown in the modal.

    Note down or keep in your clipboard the following four values before moving to AdsPower:

    - **IP address**
    - **Port**
    - **Username**
    - **Password**
  </Step>

  <Step title="Create a Browser Profile in AdsPower with Your MiyaIP Proxy">
    Open AdsPower and click **New Browser** to start creating a new browser profile.

    1. Enter a descriptive **environment name** for the profile (for example, the account or platform it will be used for).
    2. Configure any browser fingerprint parameters as needed for your use case.
    3. Scroll down to the **Proxy Configuration** section.
    4. Set the **Proxy Method** to **Custom**.
    5. Select your preferred **Proxy Type**: `Socks5`, `HTTP`, or `HTTPS`.
    6. Fill in the credential fields using the values you copied from MiyaIP:
       - **Proxy Host / IP** — the IP address from your MiyaIP dashboard
       - **Port** — the port number
       - **Username** — your proxy username
       - **Password** — your proxy password
    7. Click **Check Proxy** to test the connection. AdsPower will verify that the proxy is reachable and return a success message if everything is configured correctly.
    8. Once the check passes, click **OK** to save the browser profile.
  </Step>

  <Step title="Open the Profile and Start Browsing">
    Back on the AdsPower browser profiles list, find the profile you just created and click the **Open** button next to it.

    AdsPower will launch a new browser window for that profile, routing all traffic through your MiyaIP static residential IP.

    <Tip>
      When the browser opens, check the AdsPower **start page** — it displays the connected IP address, geographic region, and fingerprint information for that profile. Use this to confirm that your MiyaIP proxy is active and that the displayed location matches your expected IP region.
    </Tip>
  </Step>
</Steps>
