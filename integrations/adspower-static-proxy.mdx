---
title: "Use a MiyaIP static proxy in AdsPower"
sidebarTitle: "AdsPower static proxy"
description: "Download AdsPower, retrieve your MiyaIP relay proxy details, create a browser profile, and check the proxy connection."
---

Download and install AdsPower from the [AdsPower download page](https://www.adspower.net/share/miyaip), then follow these steps to configure your MiyaIP static proxy.

<Note>
  This tutorial demonstrates a **relay proxy**. Close other proxy or VPN tools on your computer before using it.
</Note>

<Steps>
  <Step title="Retrieve your proxy details">
    Log in to the MiyaIP dashboard and find the IP you want to use under **Purchased static proxies**. Retrieve its **relay proxy** details: host address (IP), port, username, and password.

    <Frame>
      <img src="/images/tutorials/5.png" alt="Retrieve relay proxy details for a purchased static proxy in MiyaIP" />
    </Frame>
  </Step>
  <Step title="Create a browser profile">
    Log in to AdsPower, then complete the following:

    1. Click **New browser** and enter the environment name and browser parameters you need.
    2. Find **Proxy configuration** and set **Proxy method** to **Custom**.
    3. Set **Proxy type** to `Socks5`, `HTTP`, or `HTTPS`, according to the proxy details you retrieved.
    4. Enter the host address (IP), port, username, and password in their corresponding fields.
    5. Click **Check proxy**. Once the test succeeds, click **OK** to save the browser profile.

    <Frame>
      <img src="/images/tutorials/6.png" alt="Enter custom proxy details in AdsPower and check the proxy" />
    </Frame>
  </Step>
  <Step title="Open the browser to use the proxy">
    In the browser profile list, click **Open** on the right of the profile to start using your MiyaIP static proxy.

    <Frame>
      <img src="/images/tutorials/7.png" alt="Open the AdsPower browser configured with a MiyaIP static proxy" />
    </Frame>
  </Step>
</Steps>
