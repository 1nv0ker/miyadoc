## Native proxy tutorials

<Note>
  These tutorials require your own working overseas network connection and a MiyaIP static residential native proxy SOCKS5 node.
</Note>

<CardGroup cols={3}>
  <Card title="iOS · Shadowrocket" icon="apple" href="/native/ios-shadowrocket">
    Set **Proxy through** to your own overseas connection for the native proxy.
  </Card>
  <Card title="Android · NekoBox" icon="android" href="/native/android-nekobox">
    Add a SOCKS5 node and set it as the overseas network group's **Landing proxy**.
  </Card>
  <Card title="Android · v2rayNG" icon="android" href="/native/android-v2rayng">
    Set your overseas node as the **Pre-proxy**, then add the MiyaIP SOCKS5 node.
  </Card>
</CardGroup>
