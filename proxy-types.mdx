This guide covers **relay proxies** and **native proxies**. For a native proxy, you supply the first overseas connection and use a MiyaIP SOCKS5 node as the second proxy layer.

## Relay proxy

Prepare the appropriate client and the relay proxy QR code provided by MiyaIP. Follow the tutorial to scan the code, import the configuration, and connect.

For AdsPower on a computer, enter your proxy details using the [AdsPower static proxy tutorial](/integrations/adspower-static-proxy). That tutorial demonstrates a relay proxy. Close other proxy or VPN tools on your computer before configuring it.

## Native proxy

Prepare the following before configuring a native proxy:

- A phone with Shadowrocket, NekoBox, or v2rayNG installed.
- Your own first-layer overseas network connection.
- The SOCKS5 node details for your MiyaIP static residential native proxy.
