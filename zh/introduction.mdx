MiyaIP 是一款住宅代理服务，提供来自全球各地的真实、经过验证的住宅 IP 地址。无论您需要稳定的长期身份用于账号管理，还是用于数据采集的轮换 IP 池，或是专为社交媒体直播优化的独立 IP，MiyaIP 都能提供灵活的选择来适配您的工作流。您可以在几分钟内通过手机或桌面设备完成接入。

## MiyaIP 的工作原理

MiyaIP 根据您是否已有海外网络环境，提供两种截然不同的使用模式。

<CardGroup cols={2}>
  <Card title="Relay Proxy (中转代理)" icon="tower-broadcast">
    MiyaIP 提供完整的中转链路。您**无需**自备海外 VPN 或代理环境。只需在您的客户端应用中配置提供的服务器地址和认证信息，MiyaIP 便会自动处理从您的设备到住宅 IP 出口节点的路由。
  </Card>

  <Card title="Native Proxy (原始代理)" icon="network-wired">
    您需要提供自己的第一跳海外网络连接（例如已有的 VPN 或代理）。MiyaIP 随后会以 **SOCKS5 住宅 IP** 作为**第二跳**，在现有连接之上叠加一层真实的住宅身份，以实现最高的真实性。
  </Card>
</CardGroup>

## AdsPower 集成

MiyaIP 可无缝集成 **AdsPower**，这款业界领先的多账号防关联浏览器。通过为每个浏览器配置分配一个独立的 MiyaIP 住宅 IP，您可以确保每个账号都在一个独特、真实的住宅身份下运行，从而大幅降低被检测或封禁的风险。

## 控制台功能

登录 MiyaIP 控制台后，您可以在一个地方管理所有代理资源：

- **查看已购 IP**：一目了然地查看所有活跃 IP 及其地区、到期时间
- **二维码导出**：为任意 IP 配置生成二维码，并直接扫描到客户端应用
- **手动续费**：在到期前按需延长任意 IP 的有效期
- **自动续费**：开启自动续费，确保关键 IP 不会意外离线
