MiyaIP 后台为你提供了一个集中管理所有已购代理 IP 的地方。在左侧边栏的**代理**（Proxy）板块中，你可以选择任意代理类型（例如静态住宅），切换到**已购 IP**（Purchased IPs）标签页，即可查看所有活跃、即将到期和已过期 IP 的完整列表。本页面将说明每一列的含义、如何获取凭据，以及如何续费和管理你的代理。

## 已购 IP 列表

已购 IP 列表中的每一行代表你拥有的一个代理 IP。列表包含以下列：

| 列 | 说明 |
| --- | --- |
| **Region**（地区） | IP 的地理位置（国家和/或城市）。 |
| **Original Proxy**（原始代理） | 直接代理地址，格式为 `host:port:user:pass`。 |
| **Relay Proxy**（中转代理） | 同一 IP 的中继地址，在直接访问受限时非常有用。 |
| **Device**（设备） | 与此 IP 关联的设备绑定（如有）。 |
| **Notes**（备注） | 你可以设置的自由文本标签，用于标识或整理你的 IP。 |
| **Status**（状态） | IP 的当前状态，详见下方的[状态指示器](#状态指示器)。 |
| **Expiry**（到期时间） | IP 授权失效的日期和时间。 |
| **Renewal**（续费） | 橙色的**续费**（Renew）按钮，用于手动延长该 IP 的订阅。 |
| **Auto-renewal**（自动续费） | 一个开关，用于启用或禁用该 IP 的自动续费。 |

## 获取代理凭据

要在应用或浏览器中使用某个 IP，你需要获取主机、端口、用户名和密码。你可以通过以下两种方式获取：

- **复制图标**：点击**原始代理**（Original Proxy）或**中转代理**（Relay Proxy）列中的复制图标，即可将完整凭据字符串即时复制到剪贴板。
- **二维码图标**：点击任意 IP 行上的二维码图标，会弹出一个凭据窗口。该窗口提供 **Shadowrocket**、**Nekobox** 和 **V2ray** 的标签页，方便你通过扫描二维码直接将这些代理配置导入到对应的移动端或桌面端客户端。

你也可以使用行上的**设备绑定图标**，将 IP 与特定设备关联，用于访问控制。

## 筛选与搜索

当你拥有大量 IP 时，可以使用内置筛选条件缩小列表范围：

- **按地区筛选**：从地区筛选器中选择国家或地区，仅显示该地点的 IP。
- **按状态筛选**：将列表筛选为仅显示活跃、即将到期或已过期的 IP。
- **按 IP 地址搜索**：在搜索框中输入 IP 地址，直接跳转到对应条目。

<Tip>
  使用**导出**（Export）按钮，可以将所有筛选结果下载为文件。这对于批量将凭据导入第三方工具，或离线保存代理清单非常有用。
</Tip>

## 续费代理

当某个 IP 接近到期日时，你可以直接从列表中进行续费：

- **手动续费**：点击该 IP 所在行的橙色**续费**（续费）按钮。你将进入续费流程，可以选择时长并完成支付。
- **自动续费**：打开任意一行上的**自动续费**（Auto-renewal）开关，MiyaIP 会在 IP 到期前自动从你的账户余额中扣款并延长授权期。VIP 会员在自动续费时享受 **55%** 的折扣。

## 状态指示器

**状态**（Status）列使用以下标签来展示每个 IP 的当前状态：

- **Active**（活跃）：IP 已上线，可以正常使用。
- **Expiring Soon**（即将到期）：IP 处于到期警告窗口内。请及时续费，以免影响使用。
- **Expired**（已过期）：IP 授权已过期。在续费之前，该代理不再可用。
