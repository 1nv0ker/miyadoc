---

本教程适用于你已准备好海外网络环境，并需要在 iPhone 上连接 MiyaIP 静态住宅原始代理的情况。

## 设备准备

1. 打开 **设置 → 隐私与安全性 → 定位服务**，关闭 **定位服务**。

<Frame>
  <img src="/images/tutorials/o_ios_sr_1.png" alt="在 iPhone 设置中关闭定位服务" style={{ width: "100%", maxWidth: "480px" }} />
</Frame>

2. 打开 **设置 → 通用**，将 **日期与时间** 的时区、**语言与地区** 调整为代理 IP 的目标国家或地区。选择目标国家的语言，避免使用简体中文。

<Frame>
  <img src="/images/tutorials/o_ios_sr_2.png" alt="在 iPhone 上调整日期、时间、语言和地区" style={{ width: "100%", maxWidth: "480px" }} />
</Frame>

你也可以参考[设备准备](/zh/device-preparation)了解这些设置。

## 连接前的准备

- 在 iPhone 上安装 **Shadowrocket**，并准备好可用的海外网络节点，作为第一层网络环境。
- 在 MiyaIP 后台准备好静态住宅 **原始代理** 的 SOCKS5 节点及二维码。确认你有代理主机、端口、用户名和密码。

<Frame>
  <img src="/images/tutorials/4.png" alt="在 MiyaIP 后台查看静态住宅原始代理的二维码和凭据" />
</Frame>

## 配置步骤

<Steps>
  <Step title="扫描原始代理二维码">
    打开 Shadowrocket，点击左上角的 **扫描按钮**，扫描 MiyaIP 后台的原始代理二维码，导入静态 IP 节点。

    <Frame>
      <img src="/images/tutorials/o_ios_sr_4.png" alt="点击 Shadowrocket 左上角的扫描按钮" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="打开节点设置">
    点击刚导入的静态 IP 节点右侧的 **感叹号按钮**，进入节点设置。

    <Frame>
      <img src="/images/tutorials/o_ios_sr_5.png" alt="点击静态 IP 节点右侧的感叹号进入设置" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="打开代理通过设置">
    在节点设置中点击 **代理通过**。

    <Frame>
      <img src="/images/tutorials/o_ios_sr_6.png" alt="在 Shadowrocket 节点设置中打开代理通过" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="选择自备的海外网络节点">
    在 **代理通过** 中选择你已准备好的海外网络节点。

    <Frame>
      <img src="/images/tutorials/o_ios_sr_7.png" alt="在代理通过列表中选择自备的海外网络节点" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="检查配置并保存">
    确认协议为 **SOCKS5**，核对 MiyaIP 原始代理的 **主机、端口、用户名和密码**。检查 **代理通过** 已选择正确的海外节点，然后点击 **保存**。

    <Frame>
      <img src="/images/tutorials/o_ios_sr_8.png" alt="检查 SOCKS5 协议和代理通过设置后保存节点" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="启动静态 IP 节点">
    返回 Shadowrocket 首页，选择 MiyaIP 的 **静态 IP 节点**。将 **全局路由** 设为 **代理**，打开顶部的 **连接开关**。

    <Frame>
      <img src="/images/tutorials/o_ios_sr_9.png" alt="选择静态 IP 节点并启动 Shadowrocket 代理连接" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="核验出口 IP">
    在浏览器中打开 [whoer.net](https://whoer.net)。确认显示的 **IP 地址** 与你购买的 MiyaIP 静态住宅 IP 一致，并检查 **国家或地区** 是否符合预期。

  </Step>
</Steps>
