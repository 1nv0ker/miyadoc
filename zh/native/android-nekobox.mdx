本教程适用于你已准备好海外网络订阅，并需要在 Android 上连接 MiyaIP 静态住宅原始代理的情况。

从 [NekoBox 1.4.2 发布页](https://github.com/MatsuriDayo/NekoBoxForAndroid/releases/tag/1.4.2)下载并安装 NekoBox。

## 设备准备

1. 打开手机 **设置**，将日期与时间的 **时区**、**语言和地区** 调整为代理 IP 的目标国家或地区。不同 Android 设备的菜单名称可能不同。选择目标国家的语言，避免使用简体中文。

<Frame>
  <img src="/images/tutorials/o_and_nb_1.png" alt="在 Android 上调整日期、时间、语言和地区" style={{ width: "100%", maxWidth: "480px" }} />
</Frame>

2. 在手机 **设置** 中找到 **位置**，关闭定位功能。

<Frame>
  <img src="/images/tutorials/o_and_nb_2.png" alt="在 Android 设置中关闭位置功能" style={{ width: "100%", maxWidth: "480px" }} />
</Frame>

你也可以参考[设备准备](/zh/device-preparation)了解这些设置。

## 连接前的准备

- 在 Android 手机上安装 **NekoBox**，并准备好可用的海外网络订阅链接，作为第一层网络环境。
- 在 MiyaIP 后台准备好静态住宅 **原始代理** 的 SOCKS5 凭据：**主机、端口、用户名和密码**。

## 配置步骤

<Steps>
  <Step title="添加节点">
    打开 NekoBox，点击首页右上角的 **加号**。

    <Frame>
      <img src="/images/tutorials/o_and_nb_3.png" alt="点击 NekoBox 首页右上角的加号" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="选择手动输入">
    在添加菜单中点击 **手动输入**。

    <Frame>
      <img src="/images/tutorials/o_and_nb_4.png" alt="在 NekoBox 添加菜单中选择手动输入" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="选择 SOCKS 协议">
    在协议列表中点击 **SOCKS**。

    <Frame>
      <img src="/images/tutorials/o_and_nb_5.png" alt="在 NekoBox 协议列表中选择 SOCKS" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="填写 MiyaIP 代理信息">
    设置一个便于识别的 **名称**。填写 MiyaIP 原始代理的 **主机、端口、用户名和密码**，确认使用 **SOCKS5**，然后点击右上角的 **✓** 保存。

    <Frame>
      <img src="/images/tutorials/o_and_nb_6.png" alt="填写 MiyaIP SOCKS5 代理信息并保存节点" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="打开侧边菜单">
    点击左上角的 **三条横线按钮**。

    <Frame>
      <img src="/images/tutorials/o_and_nb_7.png" alt="点击 NekoBox 左上角的菜单按钮" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="进入分组">
    在侧边菜单中点击 **分组**。

    <Frame>
      <img src="/images/tutorials/o_and_nb_8.png" alt="在 NekoBox 侧边菜单中打开分组" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="添加分组">
    点击分组页面右上角的 **加号**。

    <Frame>
      <img src="/images/tutorials/o_and_nb_9.png" alt="点击分组页面右上角的加号" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="填写自备的海外订阅">
    设置 **分组名称**，将 **分组类型** 改为 **订阅**。在 **订阅链接** 中填入你自备的海外网络订阅链接，然后点击右上角的 **✓** 保存。

    <Frame>
      <img src="/images/tutorials/o_and_nb_10.png" alt="设置订阅分组并填写自备的海外网络订阅链接" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="编辑订阅分组">
    找到刚创建的海外订阅分组，点击 **编辑**。

    <Frame>
      <img src="/images/tutorials/o_and_nb_11.png" alt="编辑刚创建的海外订阅分组" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="设置落地代理">
    在分组设置中点击 **落地代理**。

    <Frame>
      <img src="/images/tutorials/o_and_nb_12.png" alt="在订阅分组设置中打开落地代理" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="选择 MiyaIP 静态 IP 节点">
    选择你刚才保存的 **MiyaIP SOCKS5 节点**，将它设为该分组的落地代理。

    <Frame>
      <img src="/images/tutorials/o_and_nb_13.png" alt="选择 MiyaIP 静态 IP 节点作为落地代理" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="再次打开侧边菜单">
    点击左上角的 **三条横线按钮**。

    <Frame>
      <img src="/images/tutorials/o_and_nb_14.png" alt="再次打开 NekoBox 侧边菜单" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="返回配置页面">
    在侧边菜单中点击 **配置**。

    <Frame>
      <img src="/images/tutorials/o_and_nb_15.png" alt="在 NekoBox 侧边菜单中打开配置页面" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="连接并测试延迟">
    选择海外订阅分组中的一个 **海外网络节点**，点击下方的 **纸飞机按钮** 连接。点击 **粉色区域** 进行握手延迟测试。

    <Frame>
      <img src="/images/tutorials/o_and_nb_16.png" alt="选择海外网络节点、连接并点击粉色区域测试延迟" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="核验出口 IP">
    在浏览器中打开 [whoer.net](https://whoer.net)。确认显示的 **IP 地址** 与你购买的 MiyaIP 静态住宅 IP 一致，并检查 **国家或地区** 是否符合预期。

  </Step>
</Steps>
