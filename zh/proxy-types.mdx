MiyaIP 提供全面的代理产品线，以匹配各种使用场景：从需要固定、一致身份的长期账号维护，到受益于持续轮换 IP 池的高吞吐量数据工作流。了解每种类型之间的差异，有助于您选择合适的产品，避免不必要的成本或检测风险。

## 可选代理类型

<CardGroup cols={2}>
  <Card title="静态住宅 — Static Residential" icon="house-signal">
    一个在整个订阅期间**专属分配给您的固定住宅 IP**。IP 地址在会话之间不会变更，非常适合社交媒体账号、电商店铺以及任何对来自新 IP 或变更 IP 的登录进行标记的服务。当一致性和建立信任最为重要时，这是最佳选择。
  </Card>

  <Card title="静态住宅（日租）— Daily Rental Static Residential" icon="calendar-day">
    与标准静态套餐相同的固定住宅 IP 体验，但按**天计费**而非按月。非常适合短期活动或一次性任务，您可以在不承担长期订阅的情况下获得稳定的身份。
  </Card>

  <Card title="直播 IP TikTok — TikTok Live IP" icon="circle-play">
    **专为 TikTok 直播优化**的专用住宅 IP。这些 IP 经过精心筛选，具备低延迟、高稳定性和通往 TikTok 基础设施的干净路由，从而降低直播掉线、地区限制或直播期间账号处罚的风险。
  </Card>

  <Card title="静态数据中心 — Static Data Center" icon="server">
    托管在专业数据中心的高速、稳定 IP。与住宅选项相比，数据中心 IP 提供**更快的连接速度**和更高的在线率。最适合原始性能是首要需求且住宅级别的真实性并非严格必要的任务。
  </Card>

  <Card title="动态住宅 — Dynamic Residential" icon="arrows-rotate">
    一个**轮换住宅 IP 地址池**，在每个新连接请求时或按设定间隔自动更换。非常适合网页采集、广告验证以及任何需要从每次请求都显示为不同住宅用户的任务。
  </Card>

  <Card title="动态移动 — Dynamic Mobile" icon="mobile">
    来自**真实移动运营商网络**（3G/4G/5G）的轮换 IP。移动 IP 在大多数平台上拥有很高的信任度，对于移动优先的应用、社交媒体自动化以及运营商级 IP 信誉具有优势的场景尤其有效。
  </Card>

  <Card title="动态不限量 — Unlimited Dynamic" icon="infinity">
    **无流量上限**的动态轮换住宅 IP。专为大容量使用场景设计，例如大规模采集、批量账号操作或持续监控任务，这些场景下按流量计费的带宽成本会高得令人望而却步。
  </Card>

  <Card title="短效住宅 — Short-term Residential" icon="clock">
    **有效期很短**的住宅 IP，通常从几分钟到几小时不等。非常适合需要住宅真实性但只需短暂使用的快速、限时任务，无需为完整一天或一个月的访问付费。
  </Card>
</CardGroup>

## 中转模式与原始模式

以上每种代理类型都可以在 MiyaIP 的两种连接模式之一中使用。正确的模式取决于您是否已有海外网络环境。

<Tabs>
  <Tab title="Relay Proxy (中转代理)">
    在中转模式下，**MiyaIP 提供完整的中转链路**，您无需自备 VPN 或海外代理。您的设备连接到 MiyaIP 的中转服务器，然后由服务器将流量路由通过住宅 IP 出口节点。这是最简洁的设置方式，推荐给大多数用户。

    **何时选择中转模式：**

    - 您没有现有的海外 VPN 或代理订阅
    - 您希望获得最快、最简单的设置体验
    - 您正在配置移动设备（iOS 或 Android）
  </Tab>
  <Tab title="Native Proxy (原始代理)">
    在原始模式下，您需要提供**自己的第一跳海外连接**（例如已有的 VPN 或代理）。MiyaIP 的住宅 IP 随后被配置为**SOCKS5 第二跳**，叠加在现有连接之上。这形成了双层链路：您的设备 → 您的海外代理 → MiyaIP 住宅 IP → 目标网站。

    **何时选择原始模式：**

    - 您已有可靠的海外 VPN 或代理
    - 您需要最高的 IP 真实性（出口 IP 是纯粹的住宅 IP，没有中转指纹）
    - 您正在使用 AdsPower 或其他防关联浏览器，在这些场景中串联代理是标准做法
  </Tab>
</Tabs>

## 支持的代理协议

MiyaIP 住宅 IP 可通过以下标准协议访问，兼容所有主流代理客户端和浏览器：

| 协议 | 说明 | 推荐用途 |
| --- | --- | --- |
| **SOCKS5** | 支持所有流量类型（包括 UDP）的低层协议 | 移动应用、防关联浏览器、原始代理串联 |
| **HTTP** | 标准 HTTP 隧道代理 | 桌面浏览器、仅支持 HTTP 代理的工具 |
| **HTTPS** | 加密 HTTP 代理（基于 TLS 的 HTTP） | 桌面浏览器、需要加密代理连接的安全环境 |

<Tip>
  对于大多数使用场景，尤其是在移动设备和防关联浏览器中，推荐使用 **SOCKS5**。它拥有最广泛的兼容性，并支持所有流量类型，而不仅仅是网页浏览。
</Tip>
