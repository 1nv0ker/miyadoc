下载并安装 [NekoBox 1.4.2](https://github.com/MatsuriDayo/NekoBoxForAndroid/releases/tag/1.4.2)，然后按以下步骤配置 MiyaIP 中转代理。

## 准备 Android 手机

<Steps>
  <Step title="调整日期、时间、语言和地区">
    找到 **通用（一般）**，将手机的日期与时间设置为目标国家或地区的日期与时间。将语言改为简体中文以外的语言，优先选择目标国家的语言，并将地区改为目标国家或地区。

    <Frame>
      <img src="/images/tutorials/m_and_nb_1.png" alt="在 Android 设置中调整日期、时间、语言和地区" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="关闭定位">
    找到 **位置**，关闭定位，避免应用读取你的地理位置。

    <Frame>
      <img src="/images/tutorials/m_and_nb_2.png" alt="在 Android 设置中关闭定位" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
</Steps>

## 连接中转代理

<Steps>
  <Step title="打开添加菜单">
    打开 NekoBox 首页，点击右上角的 **加号**。

    <Frame>
      <img src="/images/tutorials/m_and_nb_3.png" alt="点击 NekoBox 首页右上角的加号" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="选择扫描二维码">
    在添加菜单中选择 **扫描二维码**。

    <Frame>
      <img src="/images/tutorials/m_and_nb_4.png" alt="在 NekoBox 添加菜单中选择扫描二维码" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>
  </Step>
  <Step title="扫描并导入 NekoBox 二维码">
    在 MiyaIP 官网打开已购 IP 的中转代理二维码，选择 **NekoBox**，扫描对应二维码并保存节点。

    <Frame>
      <img src="/images/tutorials/2.png" alt="在 MiyaIP 官网查看中转代理的 NekoBox 二维码" />
    </Frame>
  </Step>
  <Step title="连接并测试延迟">
    选择刚保存的静态节点，点击下方的 **纸飞机按钮** 连接。点击 **粉色区域** 进行握手延迟测试。如果失败或超时，关闭 **纸飞机按钮**，然后重新连接。

    <Frame>
      <img src="/images/tutorials/m_and_nb_6.png" alt="选择 NekoBox 节点、启动连接并在粉色区域测试延迟" style={{ width: "100%", maxWidth: "480px" }} />
    </Frame>

    连接后，在浏览器中打开 [whoer.net](https://whoer.net)，检查出口 IP 和地区是否与你配置的 MiyaIP 代理一致。
  </Step>
</Steps>

你也可以查看 [NekoBox 视频参考](https://www.youtube.com/watch?v=kToFOqzVfh4&t=836s)。
