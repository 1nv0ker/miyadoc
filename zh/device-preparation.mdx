配置手机代理前，关闭定位，并将设备的语言、地区和日期时间调整到代理 IP 的目标国家。中转代理和原始代理都按以下要求准备。

<Tabs>
  <Tab title="iOS">
    <Steps>
      <Step title="关闭定位服务">
        打开**设置**，在**隐私**中找到**定位服务**，关闭定位服务。

        <Frame>
          <img src="/images/tutorials/m_ios_sr_1.png" alt="在 iOS 设置中关闭定位服务" style={{ width: "100%", maxWidth: "480px" }} />
        </Frame>
      </Step>
      <Step title="调整日期时间、语言和地区">
        在**通用**中，将手机的日期、时间和时区设为目标国家对应的设置。将语言改为简体中文以外的语言，优先选择目标国家的语言；将地区改为目标国家。

        <Frame>
          <img src="/images/tutorials/m_ios_sr_2.png" alt="调整 iOS 的日期时间、语言和地区" style={{ width: "100%", maxWidth: "480px" }} />
        </Frame>
      </Step>
    </Steps>
  </Tab>
  <Tab title="Android">
    <Steps>
      <Step title="调整日期时间、语言和地区">
        在手机设置中，将日期、时间和时区设为目标国家对应的设置。将语言改为简体中文以外的语言，优先选择目标国家的语言；将地区改为目标国家。

        <Frame>
          <img src="/images/tutorials/m_and_nb_1.png" alt="调整 Android 的日期时间、语言和地区" style={{ width: "100%", maxWidth: "480px" }} />
        </Frame>
      </Step>
      <Step title="关闭定位">
        在手机设置中找到**位置**，关闭定位。

        <Frame>
          <img src="/images/tutorials/m_and_nb_2.png" alt="在 Android 设置中关闭定位" style={{ width: "100%", maxWidth: "480px" }} />
        </Frame>
      </Step>
    </Steps>
  </Tab>
</Tabs>

## 继续配置

准备完成后，返回[教程入口](/zh/introduction)，选择你的代理模式和客户端。连接后，在浏览器中访问 [whoer.net](https://whoer.net)，检查出口 IP 是否符合预期。

<Note>
  如果你使用原始代理，还需要准备可用的海外网络环境和 MiyaIP SOCKS5 节点。详细要求见[代理模式](/zh/proxy-types)。
</Note>
