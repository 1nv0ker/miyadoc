---
title: "激活 MiyaIP 代理前的设备准备"
sidebarTitle: "Device Preparation"
description: "在激活 MiyaIP 代理前，关闭定位服务并设置设备语言、地区和时区，以避免检测并匹配您的 IP 地区。"
---

在激活任何 MiyaIP 代理之前，将您的设备系统设置与代理 IP 的目标国家保持一致非常重要。应用和网站并非仅依靠 IP 地址来判断您的位置，它们还会读取设备的 GPS 坐标、系统语言、区域格式设置和时区。如果这些信号与代理 IP 的地区发生冲突，您可能会触发欺诈检测、收到错误的地区内容，或导致账号被标记。花几分钟正确准备您的设备，对代理效果有显著影响。

<Note>
  以下步骤同时适用于**中转代理**和**原始代理**模式。请在配置代理客户端应用之前完成这些准备工作。
</Note>

## 准备步骤

<Steps>
  <Step title="关闭定位服务">
    GPS 位置数据是应用验证您真实位置的最强信号之一。关闭定位服务可防止应用读取您的物理坐标，并将其与代理 IP 的地区进行对比。

    <Tabs>
      <Tab title="iOS">
        1. 打开**设置**
        2. 点击**隐私与安全**
        3. 点击**定位服务**
        4. 将**定位服务**切换为**关闭**
      </Tab>
      <Tab title="Android">
        1. 打开**设置**
        2. 点击**位置**（在某些设备上可能位于**隐私**下）
        3. 将**使用位置信息**切换为**关闭**
      </Tab>
    </Tabs>
  </Step>
  <Step title="将语言和地区设置为目标国家">
    设备的系统语言和地区格式（货币、日期格式、度量单位）可以被应用和浏览器读取。将这些设置与代理 IP 的目标国家相匹配，以呈现一致的身份。

    <Tabs>
      <Tab title="iOS">
        1. 打开**设置**
        2. 点击**通用**
        3. 点击**语言与地区**
        4. 在 **iPhone 语言**下，选择目标国家的语言
        5. 在**地区**下，选择对应的国家
        6. 在提示时确认更改，设备界面将重新启动
      </Tab>
      <Tab title="Android">
        1. 打开**设置**
        2. 点击**常规管理**（三星）或**系统**（原生 Android）
        3. 点击**语言**
        4. 点击**添加语言**并选择目标国家的语言
        5. 将其拖动到列表顶部，设为首选语言
        6. 在提示时确认更改
      </Tab>
    </Tabs>
  </Step>
  <Step title="将日期和时间设置为目标国家的时区">
    时区不正确是一个细微但可被检测的不一致性：您的 IP 可能解析到美国，而设备时钟却在 UTC+8。将时区设置为与代理 IP 地区一致。

    <Tabs>
      <Tab title="iOS">
        1. 打开**设置**
        2. 点击**通用**
        3. 点击**日期与时间**
        4. 如果已开启，关闭**自动设置**
        5. 点击**时区**并搜索目标国家的城市
      </Tab>
      <Tab title="Android">
        1. 打开**设置**
        2. 点击**常规管理**（三星）或**系统**（原生 Android）
        3. 点击**日期和时间**
        4. 如果已开启，关闭**自动确定时区**
        5. 点击**选择时区**并选择与目标国家对应的时区
      </Tab>
    </Tabs>
  </Step>
</Steps>

## 更改设置后

如果设备在应用语言或地区更改后提示重启，请在继续操作前重启设备。这可以确保所有系统级更改生效并对所有应用可见，而不仅仅是主屏幕。

<Warning>
  在访问目标地区服务时，**请勿**将简体中文设为设备语言。务必将设备语言设置为目标国家的语言（例如，美国代理使用英语，日本代理使用日语）。语言设置不匹配是地区检测失败的常见原因。
</Warning>

## 验证您的连接

完成设备准备并在客户端应用中激活 MiyaIP 代理后，在使用目标服务前请确认一切正常工作。

<Steps>
  <Step title="打开设备的浏览器">
    使用 Safari（iOS）或 Chrome（Android），请勿使用可能自带代理或 VPN 设置从而干扰的第三方浏览器。
  </Step>
  <Step title="访问 whoer.net">
    在浏览器中打开 [**whoer.net**](https://whoer.net)。该工具会显示您当前的 IP 地址、检测到的国家、语言、时区及其他浏览器指纹信号。
  </Step>
  <Step title="检查结果">
    确认以下内容与目标国家一致：

    - **IP 地址**：应解析到正确的国家和地区
    - **时区**：应与您在第 3 步中设置的时区一致
    - **语言**：应反映您在第 2 步中设置的语言

    如果任何值不正确，请仔细检查客户端应用中的代理配置，并确保所有设备准备步骤都已完成。
  </Step>
</Steps>

<Tip>
  如需进行更深入的指纹检查，尤其是当您在使用 AdsPower 或其他防关联浏览器时，还可以访问 [**browserleaks.com**](https://browserleaks.com) 来检查 WebRTC 泄露、Canvas 指纹和时区一致性。
</Tip>
