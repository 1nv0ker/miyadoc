---

本指南将带你完成在 AdsPower 浏览器配置文件中使用 MiyaIP 静态住宅代理的完整工作流，包括在 MiyaIP 后台找到代理凭据，在 AdsPower 中创建完全配置的浏览器环境，以及验证连接是否正常工作。完成后，你的 AdsPower 配置文件将通过你所选的 MiyaIP 住宅 IP 路由所有流量。

<Note>
  如果你使用的是**中转代理**而非原始代理，请务必在连接前关闭电脑上运行的其他 VPN 或代理软件。同时运行多个代理或 VPN 客户端可能会导致连接冲突，使中转代理无法正常工作。
</Note>

## 设置步骤

<Steps>
  <Step title="在 MiyaIP 后台提取代理凭据">
    登录你的 MiyaIP 账号，访问 [miyaip.com](https://miyaip.com)，然后在左侧边栏导航至**静态住宅**板块。

    在**已购 IP**（Purchased IPs）标签页中，找到你要使用的 IP 所在行。有两种方式可以获取凭据：

    - **复制图标**：点击**原始代理**（Original Proxy）或**中转代理**（Relay Proxy）列中的复制图标，将完整代理字符串复制到剪贴板。该字符串包含 IP 地址、端口、用户名和密码。
    - **二维码图标**：点击所在行的二维码图标，会弹出一个显示代理详情的窗口。该窗口包含 **Shadowrocket**、**Nekobox** 和 **V2ray** 等标签页，但在 AdsPower 集成中，你只需要窗口中显示的原始 IP、端口、用户名和密码值。

    在进入下一步之前，请记下或保留在剪贴板中以下四个值：

    - **IP 地址**
    - **端口**
    - **用户名**
    - **密码**
  </Step>
  <Step title="在 AdsPower 中创建带 MiyaIP 代理的浏览器配置文件">
    打开 AdsPower，点击**新建浏览器**（New Browser）开始创建新的浏览器配置文件。

    1. 为配置文件输入一个描述性的**环境名称**（例如，它所对应的账号或平台）。
    2. 根据你的使用场景配置所需的浏览器指纹参数。
    3. 向下滚动至**代理配置**（Proxy Configuration）部分。
    4. 将**代理方式**（Proxy Method）设置为**自定义**（Custom）。
    5. 选择你偏好的**代理类型**（Proxy Type）：`Socks5`、`HTTP` 或 `HTTPS`。
    6. 使用从 MiyaIP 复制的值填写凭据字段：
       - **代理主机 / IP**：你在 MiyaIP 后台获取的 IP 地址
       - **端口**：端口号
       - **用户名**：你的代理用户名
       - **密码**：你的代理密码
    7. 点击**检测代理**（Check Proxy）测试连接。AdsPower 会验证代理是否可达，如果配置正确，将返回成功消息。
    8. 检测通过后，点击**确定**（OK）保存浏览器配置文件。
  </Step>
  <Step title="打开配置文件并开始浏览">
    回到 AdsPower 浏览器配置文件列表，找到刚创建的配置文件，点击旁边的**打开**（Open）按钮。

    AdsPower 将为该配置文件启动一个新的浏览器窗口，所有流量都会通过你的 MiyaIP 静态住宅 IP 进行路由。

    <Tip>
      浏览器打开后，请查看 AdsPower **起始页面**，它会显示该配置文件所连接的 IP 地址、地理位置和指纹信息。你可以借此确认 MiyaIP 代理已生效，且显示的位置与你预期的 IP 区域一致。
    </Tip>
  </Step>
</Steps>
